=> Tic Tac Toe Game

=> About the Project
This is a simple two-player Tic Tac Toe game developed using HTML, CSS, and JavaScript. Players take turns placing O and X in a 3x3 grid. The first player to match three symbols horizontally, vertically, or diagonally wins the game.

=>Technologies Used
- HTML
- CSS
- JavaScript

 =>Features
- Two players can play the game.
- Displays the winner when three matching symbols are aligned.
- Reset Game button to restart the game.
- New Game button to start a new match.
- Prevents clicking the same box more than once.

=> How to Run
1. Open the project folder.
2. Open the `index.html` file in a web browser.
3. Start playing the game.
